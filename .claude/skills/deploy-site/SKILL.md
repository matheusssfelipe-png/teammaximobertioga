# 🚀 Deploy Site - Team Máximo Bertioga

Automação completa para fazer deploy do site na Vercel.

## O que faz

- ✅ Verifica mudanças no git
- ✅ Faz commit automático
- ✅ Faz push para o master
- ✅ Verifica se Vercel está atualizando
- ✅ Hard refresh do navegador

## Como usar

```bash
/deploy-site
```

## Workflow

1. **Verificar status** - mostra arquivos modificados
2. **Confirmar mudanças** - você confirma o que vai upar
3. **Commit automático** - faz o commit com mensagem descritiva
4. **Push para Vercel** - envia para o repositório
5. **Aguardar deploy** - espera a Vercel atualizar
6. **Verificação** - confirma que o site foi atualizado

## Exemplos

**Deploy de mudanças visuais:**
```
/deploy-site
→ Mudanças em CSS e design
→ Confirma
→ Deploy feito!
```

**Deploy de textos atualizados:**
```
/deploy-site
→ Textos da seção hero atualizados
→ Confirma
→ Deploy feito!
```

## Dicas

- Use depois de fazer mudanças no HTML
- Ideal para design tweaks e atualizações de texto
- Verifica automaticamente se tudo está OK na Vercel
- Hard refresh (`Ctrl+Shift+R`) é automático depois
